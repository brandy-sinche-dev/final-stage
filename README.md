##FINAL STAGE##

ALCANCE 
El proyecto consiste en el desarrollo de un videojuego de tipo plataforma en 2D, orientado a computadoras personales, en el cual el jugador controla a un personaje que debe superar distintos niveles llenos de obstáculos, enemigos y desafíos. El juego incluirá mecánicas básicas como salto, desplazamiento lateral, recolección de objetos y combate simple contra enemigos.

Tecnologia usada

- Godot v4.6.1
